# Business-analysis artifacts

This section will connect one Mortuary T workflow from business need through
validation.

## Planned traceability chain

```text
Business need
  -> requirement
  -> user story
  -> acceptance criteria
  -> process flow
  -> UAT scenario
  -> test result
  -> release decision
```

## Planned artifacts

- Stakeholder and actor summary
- Current or proposed workflow
- Business rules and decision points
- User story with testable acceptance criteria
- UAT scenario and expected results
- Sanitized sample defect and retest record
